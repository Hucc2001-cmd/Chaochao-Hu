# SAB 备考通 🇮🇹

一个纯前端、离线可用的小工具，帮你利用碎片时间自学、自测意大利
**SAB（Somministrazione Alimenti e Bevande，原 REC）食品饮料经营资质**课程。

> 本项目内容按托斯卡纳大区（Regione Toscana）常见 SAB 课程大纲整理归纳，
> 覆盖各大区普遍适用的核心知识框架（法规、卫生、商品学、劳动法、税务、
> 经营管理等）。**这不是官方课程，也不是真题库**，只是辅助记忆和自测的
> 工具，请务必以你报名的线下/线上课程讲义、以及官方资料为准，把这个
> App 当作课后刷题和碎片时间复习的补充。

## 这个 App 能做什么

- 📚 **8 个单元的课文讲解**：中文讲解 + 意大利语关键术语，覆盖开业资质、
  食品卫生 HACCP、食品饮料商品学、酒精销售法规、职场安全、劳动法、
  民商法税务、经营管理 8 大板块。
- 🗂️ **术语速查卡片**：每个单元自带一批「意大利语 + 中文解释」的专业词汇
  卡片，也可以在「词汇」页跨单元搜索。
- 📝 **多种自测模式**：按单元测试、随机混合测试（10题/20题/全部）、
  只测错题、10分钟速练——选择题作答后立刻自动判分并给出中文讲解。
- ❌ **错题本**：答错的题目自动收集，答对一次就从错题本移除，方便针对性
  复习，直到全部清空。
- 🔥 **学习激励（游戏化）**：经验值 XP、连续打卡天数、成就徽章，让每天
  学 10-20 分钟也有正反馈。
- 📴 **离线可用**：内置 Service Worker，第一次打开后即使没有网络也能继续
  刷题（适合通勤路上、飞机上）。
- 💾 **本地存储 + 备份**：学习进度保存在浏览器本地（不需要注册账号），
  首页可以导出/导入 JSON 备份，方便换设备或分享给别人预置进度。
- 🤝 **方便分享给同样要考证的人**：整个项目就是纯静态网页，把仓库部署到
  GitHub Pages（或任何静态托管）后，发个链接给朋友就能直接用手机打开、
  添加到主屏幕像个 App 一样使用。

## 目录结构

```
index.html              页面入口
css/style.css           全部样式（浅色/深色自适应）
js/data.js              ⭐ 全部课程内容：单元、课文、术语、题库、徽章
js/storage.js           本地存储 + 经验值/连续打卡/错题本/徽章逻辑
js/quiz.js              测试引擎：抽题、乱序、判分
js/app.js               页面渲染与路由（无框架，原生 JS）
manifest.webmanifest    PWA 配置（可"添加到主屏幕"）
service-worker.js       离线缓存
```

## 本地运行

不需要安装任何依赖，是纯静态页面。推荐用一个简单的本地服务器打开
（直接双击 `index.html` 用 `file://` 打开也能用，只是离线缓存功能不会
生效）：

```bash
# 在项目根目录下
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080
```

## 部署给其他考生使用

最简单的方式是用 **GitHub Pages**：

1. 仓库 Settings → Pages → 选择要发布的分支和根目录 `/`。
2. 保存后几分钟内会生成一个公开访问链接。
3. 把链接发给需要考证的朋友，他们用手机浏览器打开后，选择"添加到主屏幕"，
   就会有一个独立图标，打开体验接近原生 App。

也可以直接把整个文件夹拖进 Netlify / Vercel / Cloudflare Pages 之类的静态
托管平台，效果一样。

## 如何补充/修改课程内容（不需要懂编程也能改）

**所有内容都集中在一个文件里：`js/data.js`。** 打开这个文件你会看到四个部分：

1. `UNITS`：单元列表（标题、图标、简介）。
2. `LESSONS`：每个单元的课文正文（`sections`，若干个 `{heading, points}`）
   和术语卡片（`glossary`，若干个 `{term, full, zh}`）。
3. `QUESTIONS`：每个单元的题库，每道题格式是：
   ```js
   { id: "u1q1", q: "题干", options: ["选项A","选项B","选项C","选项D"], answer: 0, explain: "答案讲解" }
   ```
   `answer` 是正确选项在 `options` 数组里的下标（从 0 开始）。
4. `BADGES`：成就徽章定义，一般不需要改。

### 想换成你自己上课的真实讲义/真题该怎么做？

- 新增一道题：在对应单元的 `QUESTIONS.uX` 数组里，按上面的格式追加一个
  对象，`id` 保证全局不重复即可（比如 `u1q9`、`u1q10`）。
- 新增一个术语卡片：在对应单元 `LESSONS.uX.glossary` 数组里追加
  `{term, full, zh}`。
- 新增一个新单元：在 `UNITS` 里加一条 `{id:"u9", icon:"...", title:"...", titleIt:"...", summary:"..."}`，
  然后在 `LESSONS` 和 `QUESTIONS` 里分别补上 `u9` 对应的内容，其他代码不用改，
  首页/单元列表/测试设置页都会自动识别出新单元。
- 想直接把 PDF 讲义或历年真题发给我（Claude），我可以帮你按这个格式批量转换、
  校对并提交更新。

## 后续可以扩展的方向（供参考）

- 间隔重复（spaced repetition）：根据错题次数和上次做对的时间，智能安排
  复习顺序，而不是完全随机。
- 语音朗读意大利语术语，帮助记忆发音。
- 多套地区大纲切换（比如再补一份伦巴第大区版本），首页可以切换"我的大区"。
- 学习小组功能：几个一起考证的朋友互相看学习进度、比拼连续打卡天数。
- 把课文和题目换成双语呈现（意大利语原文 + 中文翻译）以更贴近真实考试用语。

以上这些目前都还没做，是为了先把"能学、能测、能反复刷、能离线用、能分享"
这个最小闭环跑通。你使用一段时间后感觉哪个方向最需要，随时可以继续加。
